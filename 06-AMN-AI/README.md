# AMN AI — Smart Event Safety and Cybersecurity Concept

**Status: Prototype concept; production features are not claimed.**

AMN AI explores a connected wearable and role-based operations platform to support safety, accessibility, incident response and cybersecurity at large events.

## Core concept
A visitor bracelet and operational dashboard work together to demonstrate navigation prompts, safety alerts and coordinated response.

## Proposed roles
- Visitor: bilingual Arabic/English experience, accessible prompts, navigation and SOS.
- Event administrator: operations overview and role administration.
- Cybersecurity team: security monitoring and incident triage.
- Maintenance team: device and infrastructure service workflows.
- Medical / ambulance staff: triage incoming SOS events and follow a visitor's last known location on a demonstration map.

## Accessibility directions
Consider visual, auditory and motor-access needs using multiple feedback channels, readable contrast, scalable text, clear language, vibration and equivalent alternative flows. Accessibility claims require testing with users and assistive technologies.

## Security considerations
Role-based authorization on the server, data minimization, consent where applicable, secure device pairing, SOS event integrity, privacy-conscious location handling and audit logging.
