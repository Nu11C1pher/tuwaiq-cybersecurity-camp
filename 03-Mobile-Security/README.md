# Mobile Security and Reverse Engineering

## Lab environment
A controlled Android training environment for static and dynamic analysis.

| Tool | Intended use |
| --- | --- |
| ADB / Android Studio | Device or emulator connectivity and debugging |
| JADX | Inspect decompiled Android code |
| Apktool | Decode resources and application structure |
| Frida / frida-server | Authorized dynamic instrumentation |
| Objection | Frida-powered interactive exploration |
| Ghidra | Analyze native binaries where relevant |

## Documentation queue
1. Installation and tool-version verification.
2. Emulator / test-device setup.
3. Static analysis on a permitted sample.
4. Dynamic analysis observations and mitigations.
5. Lab report with sanitized screenshots.

No APK, proprietary app binary, device identifier, or bypass script is included until release rights and scope are reviewed.
